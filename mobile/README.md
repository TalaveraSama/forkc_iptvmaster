# IPTVMaster mobile app (Android APK)

This folder packages the IPTVMaster admin panel as an installable Android app
using [Capacitor](https://capacitorjs.com). The app bundles the same React
editor the server serves and talks to your IPTVMaster server over the LAN.

Because the panel is served from inside the APK (a local `https://localhost`
origin) while the server lives on another host, the app cannot use the browser
build's `SameSite=Strict` session cookie. Instead it:

1. asks for the **server address** (e.g. `http://192.168.1.50:8080`),
2. signs in once and stores a long-lived **bearer token**, and
3. sends that token in the `Authorization` header on every API call.

The server side that makes this possible (bearer-token endpoints, opt-in CORS
for the app origin) is documented in [`../docs/MOBILE_APP.md`](../docs/MOBILE_APP.md).

## Prerequisites

- Node.js 22+ and npm 10+
- Android Studio (Ladybug or newer) with the Android SDK
- **JDK 21** (Capacitor 8 / AGP 8.7+ requires it)

## Build the APK

From the **repository root**:

```sh
# 1. Build the web app in mobile mode (sets the bearer-token connection flow)
#    and copy the result into Capacitor's webDir (mobile/www).
npm run build:mobile -w @iptvmaster/web
npm run sync --prefix mobile      # copies dist -> mobile/www and runs cap sync

# 2. (first time only) create the native Android project.
#    Already generated in this checkout; safe to skip.
npm run add:android --prefix mobile

# 3. Build a debug APK with Gradle.
npm run build:apk --prefix mobile
# -> mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

Or open it in Android Studio and run it on a device/emulator:

```sh
npm run open:android --prefix mobile
```

For a signed release build, create an upload keystore and configure
`mobile/android/app/build.gradle` (signingConfigs) as described in the
[Android docs](https://developer.android.com/build/build-variants#sign).

## Using the app

1. Install the APK on a device on the same network as the server.
2. Open it and enter the server address, e.g. `http://192.168.1.50:8080`.
3. Sign in with your IPTVMaster administrator username and password.

The server address and token are stored on the device. "Change server" and
sign-out clear them.

## Notes & security

- **Cleartext HTTP is intentional.** IPTVMaster targets trusted LAN use and is
  normally reached over plain HTTP, so the app permits cleartext traffic via
  `android/app/src/main/res/xml/network_security_config.xml`. If you terminate
  TLS, you can forbid plaintext there.
- The bearer token is stored in the app's local storage and is revocable
  server-side (sign-out deletes it; the maintenance job prunes expired tokens).
- The API only accepts cross-origin requests from the Capacitor origins listed
  in `IPTVMASTER_MOBILE_ORIGINS`, and never with cookies — only the bearer
  token. See [`../docs/MOBILE_APP.md`](../docs/MOBILE_APP.md).

## Files

- `capacitor.config.ts` — Capacitor app id/name and the `https://localhost`
  Android scheme (one of the API's allowed CORS origins).
- `sync-web.mjs` — copies `apps/web/dist` into `www/` for `cap sync`.
- `android/` — the generated native project (Gradle). Build output is git-ignored.
- `www/` — the copied web bundle, regenerated by `npm run sync --prefix mobile`.
